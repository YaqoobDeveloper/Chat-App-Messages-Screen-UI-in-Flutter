# Chat App Messages Screen UI in Flutter 💬✨

A modern and clean **chat app messages screen UI** built with Flutter.

This project focuses on creating a polished messaging experience with a clean layout, message bubbles, user information, and a responsive interface.

## ✨ Features

- 💬 Modern chat messages screen UI
- 🎨 Clean and minimal design
- 👤 User profile and chat information
- 📨 Styled incoming and outgoing messages
- ⌨️ Message input interface
- 🧩 Reusable Flutter widgets
- 📱 Responsive layout
- ⚡ Lightweight and fast UI
- 🎯 Clean and organized code

## 🛠️ Built With

- **Flutter 3.47.2**
- **Dart**

## 📋 Requirements

- Flutter **3.47.2** or compatible version
- Dart SDK included with Flutter
- Android Studio or VS Code
- Xcode for iOS development

## ▶️ Run

### 1. Clone the repository

```bash
git clone https://github.com/YaqoobDeveloper/Chat-App-Messages-Screen-UI-in-Flutter.git
```

### 2. Navigate to the project

```bash
cd Chat-App-Messages-Screen-UI-in-Flutter
```

### 3. Install dependencies

```bash
flutter pub get
```

### 4. Run the app

```bash
flutter run
```
